## 问题

后续用户实际首次使用暴露了共享PIN初始化缺口。[v0.8家长验证首次设置](parent-onboarding.md)单独替换该初始化及修改流程；本记录的无解释正文、明确字段与短状态要求继续有效。下述“不改变服务端”等边界和47项结果属于v0.7当次交付，不限制已授权的v0.8修复，也不证明新家庭首次配置可用。

首页、表单、背包、核验和设置堆有规则解释、实施注释、示例与操作教学。用户需要阅读长文才能理解下一步，界面重复表达已经存在于字段、控件和数值中的信息。

## 方向与变更范围

- 移除系统提供的说明段落、帮助脚注、默认AI教学、示例占位文字、技术实现细节和重复副标题；从实际渲染源删除，不以CSS隐藏、折叠说明或tooltip迁移代替。
- 保留功能名称、字段标签、真实名称/原因/备注等用户内容、金额/数量/时间/进度、简短状态和动作。用户写入的提醒备注与加分事实是业务内容，不属于要删的系统说明。
- 必需后果由局部结构表达：购买用单价、数量、总价和余额算式；免费/道具用按钮来源和剩余数量；核验展示本次对象与金额；模板同名用短状态与“选用已有”动作；缺输入、冲突、断网使用短结果与可执行控件。
- 能力和权限不能因删说明而误导。保留“本机/共享”“指令演示/模型名称”“未开启/不支持”“PIN/算术题”等真实状态；不增加虚构可用能力。离线演示与弱核验边界由交付文档记录。
- 控件具备可访问名称和键盘焦点。维持至少48px主要触控目标、16px输入字号、首页无滚动、搜索页码与草稿保留。
- 不改变服务端、账本、身份验证、玩法定价、成长/探索、持久化或数据格式；不修改现有家庭数据和v0.6版本证据。

## 替代方案

单纯删空所有文字会让金额、来源、字段和错误失去语义；纯图标也会增加猜测。采用具体名称配合可见数值、状态与动作。将说明放入折叠帮助或tooltip仍不符合全界面要求，因此不采用。

## 验收条件

1. 实际逐屏检查积分/提醒、常用选择与管理、各编辑器、核验/初次PIN、兑换/审批、成长/伙伴/背包/补给/探索、记录、设置、语音/AI及异常，系统说明段落和示例消失。
2. 不把动态系统解释或后端错误原文重新泄漏至界面；实际输入与查询结果保留，异常仍能定位原因并恢复。
3. 常用/DIY与保存模板、逐笔核验、免费/库存照料和购买、兑换、提醒、资料、设置、AI回填/取消链仍可真实点击完成。
4. 1024×768、390×844、320×568等既有尺寸无首页滚动/裁切，主要控件可达。清理段落后的面板不留下无意义空白。
5. 源码与离线HTML一致，file/HTTP离线仍本机模式；保留v0.6版本文件及证据。只对实际运行的本轮检查报告通过。

## 实现与修正

对象、价格、数量、余额、核验和能力状态改为局部字段列表。系统错误和AI澄清由呈现层映射，查询答复保留金额、礼品名、日期与事项；后端契约继续保持原样。映射先识别固定返回类型，再处理缺字段；默认教学例句或对象名称中的“PIN”“多少积分”等词不能改变反馈含义。多指令、指令长度、字段错误、服务失败和目标冲突分别表达；同名礼品不凭名字补入不确定的价格。

实际预览发现加分输入7时摘要仍显示5，已改为输入时原位同步；空值显示“—”，不回填5，也不重建数字输入框。该问题加入最终回归，不以原来的核验金额正确代替可见摘要正确。人工实读还发现未知指令被误问分值，按固定返回语义修正并追加反例断言；短句长度和关键词扫描不能替代语义验收。
