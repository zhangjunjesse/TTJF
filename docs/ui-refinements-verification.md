# 积分与表单体验验证

2026-11-17，基于 `cd1f13d` 的 `codex/farm-ui-refinements` 本地改动。验证使用独立合成家庭、临时 SQLite/HTTP 服务和桌面 Edge，没有向本地真实家庭写入积分或兑换数据。

## 改动与覆盖

| 用户反馈 | 实现 | 验证 |
| --- | --- | --- |
| 输入区过高、边框重复 | 外置标签、单层原生输入边框、约 48px 高度 | 905×892、390×844、320×568 的真实控件尺寸和截图 |
| 家长 PIN 不明显 | 全局居中弹框、PIN 前置、自动聚焦、内部滚动 | 焦点、触达、屏幕边界与 320px 摘要完整滚动 |
| 常用行为变成长条 | 内容驱动的行高与固定图标比例 | 1、2、4 项数据下的卡片尺寸；窄屏按原规则最多显示 2 项 |
| 创建模板与真实加分混淆 | 编辑/星星图标、明确文字、加分核对后再验证 | 模板不增分、确认前无 challenge/写入、取消保留草稿、错误 PIN、键盘 Enter、重复点击只写一笔 |
| 积分展示缺少情绪反馈 | 共用渲染器的 Three.js 星星宝箱和成功庆祝 | 实际授权写入后动画、透明投影、减少动画、帧率、上下文恢复及 GPU 资源释放 |
| 缺少兑换记录入口 | 礼品页进入现有兑换账本 | 页签、列表内容、筛选与返回焦点保持；查看记录不写业务状态 |
