# 小小向前：v0.1 网站式 Demo（已替换）

日期：2026-11-14。此文件保留前一轮设计被替换的原因，不再描述当前 App 界面。

v0.1 使用固定侧栏、页眉、任务主栏与积分/心愿辅助栏，手机缩成纵向页面，编辑操作切换为独立整页。它完成了任务、积分、兑换、共享持久化、草稿和原创图片/声音的运行验证，曾通过 38 项数据测试及 18 项浏览器检查。

用户在体验后明确否定：“要做成 app 式的……完全按照 web 网站设计……不行”。因此，不再以隐藏导航、压缩卡片或调整间距作为解决方案；旧版页面组织已撤回。

当前界面方向、依据、保留规则、替代选择、边界和验证义务统一由 [App 式交互决策 v0.2](app-design.md) 持有。v0.1 的运行模型、正向积分、版本同步、幂等处理、静态离线方案及旧设备能力检测被保留，布局、整页表单与对应界面验收被替换。

上一版完整源码与原始决策已保存在本工作区 `export/little-steps-web-v1.zip`；此历史归档不作为当前交付内容。正式业务需求仍由 [家庭看板需求文档](家庭看板需求文档.md) 持有，未定业务问题未因界面改版被定案。
