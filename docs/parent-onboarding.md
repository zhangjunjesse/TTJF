# v0.8 家长验证首次设置（Current）

日期：2026-11-15。依据用户在v0.7实际使用中的纠正：家长应该在“家长验证设置”页面直接设置PIN，不能要求验证一个未取得的初始密码。

2026-11-16更新：[v0.13多家庭SaaS](saas-design.md)拥有账号和租户边界。本文继续拥有逐笔核验和PIN交互；SaaS首次设置必须由该家庭已验证的owner执行。邀请成员parent不能抢先设置，匿名访问不能进入家庭。旧单户/离线部分仅为兼容路径。

## 问题

共享版在初始化时生成随机PIN，只在控制台展示。页面将首次设置和已有密码修改混为一条受限流程，导致家长在设置页填写新PIN后，被要求验证未知旧PIN。旧消费者测试使用预设PIN，未覆盖真正新家庭的首次使用。

本记录局部替换[核心设计](core-redesign.md)的随机初始PIN及首次配置决定。核心设计继续拥有逐笔授权、权限清单、限速和账本边界；[自解释界面](self-explanatory-ui.md)继续拥有无教学、注释或解释性正文的要求。

## 决定

- 新家庭默认未设置。在现有设置页选择PIN或算术题；PIN用“设置PIN”“确认PIN”两项输入直接保存，不要求旧密码，不一致不写入。
- 已设置时显示当前方式。修改PIN用“新PIN”“确认新PIN”，再按当前方式核验；核验字段明确为“当前PIN”。当前PIN输入兼容旧版6至12位凭据，新PIN为6位。算术方式隐藏并禁用PIN字段。
- 首次受限业务可以在核验面板设置两次PIN。设置成功后，仅在内存中用本次新PIN完成原动作的正常challenge与grant，不要求第三次输入。取消和迟到响应不执行原业务。
- 设置和原业务是两笔事务。自动续办只允许原业务确认版本上的一次配置提交，即revision恰好+1；如果填PIN或恢复响应期间还有其他提交，保留已经成功的PIN设置，原业务回草稿重新确认。
- SaaS日常公开操作先要求登录与家庭成员资格，家长逐笔核验仍没有全局解锁模式；账号系统由SaaS决定拥有。旧离线入口提供相同PIN可见流程，仍只是浏览器本机演示。

## 授权与持久化边界

私有parent支持`{configured:false,method:null}`；新数据不生成随机PIN。SaaS只允许已验证的家庭owner首次设置；PARENT_PIN仅是旧单户文件服务的首次预配置参数，不能覆盖已有状态，也不用于配置SaaS家庭。旧文件有凭据而无configured标记时的兼容读取仍保留凭据并标为已配置，绝不全局解锁。SaaS私有导入要求经过校验的完整envelope，不自动处理旧真实文件；未配置却已有敏感配置收据属于无效数据。

meta和snapshot只公开revision及parent的configured、method；客户端按版本拒绝迟到配置状态。POST /api/action的服务器专有parent.setup仅在权威私有状态未配置时接受，不能由客户端标志覆盖。首次PIN必须6位且确认相同；算术可以没有PIN，不生成隐藏凭据。该动作不加入日常公开操作白名单。

配置保存原子提交revision、动作ID与加盐scrypt收据。处理顺序保持精确重放、版本检查、配置与授权检查；相同提交幂等，两设备不同提交只能一次成功。配置成功后再次初始化返回PARENT_ALREADY_CONFIGURED与最新snapshot；未配置的其他受限动作返回PARENT_SETUP_REQUIRED。parent.configure继续需要当前逐笔授权；从无PIN的算术方式切到PIN必须提供有效新凭据。

PIN及确认值不写草稿、公开状态、可导出的诊断或日志。临时值在完成、取消或冲突后清除。恢复本次配置的成功结果不等于可以对更新后的业务版本自动授权。

## 取舍与后果

保留控制台初始码会继续阻塞家长；公开默认PIN会使孩子也可直接通过；对全部历史数据自动重置会破坏既有权限；公开“忘记PIN”直改会绕过已经设置的密码。这些方案均未采用。

SaaS未初始化家庭由已验证owner设置；并发首设只能成功一次。旧单户兼容服务仍由第一次成功保存者建立验证方式。算术仍是轻量防误触，不提供与PIN相同的隔离能力。配置成功但原业务未成功时，PIN仍有效，业务必须重新确认；不能为追求一键完成而忽略其他设备的版本变化。

## 已知演示数据的单次修复

本次只修复用户实际打开的4178本机演示。停旧进程后，验证该文件仍是revision5、无配置收据、旧初始化凭据格式；保存完整私有备份，再只将parent改为未配置、revision改为6，并在同一地址重启。没有修改业务state、receipts及appliedActions，也没有重置其他数据文件或保留通用reset开关。

[迁移核对](../artifacts/v8-preview-migration.json)证明备份与原文件一致、业务state和收据散列不变。[实际预览验证](../artifacts/v8-live-preview.json)记录新页面显示“设置家长验证”及两个空PIN输入，无旧密码面板、无横向溢出、无写请求和脚本错误；[实际截图](../artifacts/v8-live-setup.png)是该预览的只读检查。用户自己的PIN没有被测试代设。
