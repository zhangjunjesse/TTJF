## 建议这样试

1. **统一记分**：积分首页点“加分”直接选择项目，或点导航栏＋新增；也可直接点首页常用快捷。选中后进入可编辑表单，返回保留草稿，顶部“加分”提交。自定义时可勾选“同时存为常用”：本次名称、分值和原因将同时成为新模板，一次确认、一次家长核验完成两件事；取消、失败或同笔重试不会留下半份记录或重复模板。已有同名项时显示同名状态，并可选用已有项；原项不会被覆盖。选了已有模板后改本次分值，也不会修改模板。
2. **指令填写**：当前未接通真实模型，使用本地规则演示。在加分表单点击顶部星光图标展开指令，描述“自己收好了书包，加 5 分”，点“填写”，核对生成的草稿后再提交；“同时存为常用”由表单上的明确选择决定。管理常用项从选择器的编辑图标进入，再展开指令，可新增、改名、改分、停用或启用。管理模板不直接给孩子加分；仅打开、选择或取消不增加使用次数。
3. **每天陪伙伴探索**：投喂、清洁、训练共用全家每天 3 次免费机会；每次成功照料增加 1 探索进度，当天三种各完成一次再额外加 1。三次免费完成不同照料即可达到 4，解锁并立即进入微光森林。按钮标明本次使用免费机会还是库存，已完成的种类显示勾记。点伙伴摸摸永远免费、不消耗资源，也不产生探索进度。
4. **补充道具**：“背包·探索”中查看库存、进入补给或收藏。能量果、星露瓶、训练球各 3 积分，每次可买 1–10 件；先查看总价与购买后的余额，再逐笔家长核验。购买只入背包，不自动使用；之后孩子可自行消耗。没额度、没库存不会自动扣分购买，失败不会悄悄改用另一种资源。
5. **切换伙伴与场景**：“背包·探索”顶部点设置图标，可选择晶叶幼龙或太空探险水豚，原昵称保留。五阶段由累计获得积分决定；“探索收藏”中按里程解锁六处地点与徽章，解锁后可以自由切换。普通照料不改变手选场景，新解锁时会自动前往新地点。换伙伴不会刷新额度或重置成长、库存与收藏。
6. **孩子资料**：点击首页孩子头像/名称，修改昵称、选择照片或移除头像，预览后通过家长核验保存。
7. **孩子兑换**：点“兑换”选择礼品并申请，此时不扣分；家长核验确认时重验余额与资格。礼品和道具使用同一余额，购买道具后可能暂时不够兑换先前申请的礼品。新增/管理礼品在兑换面板内，待审批从顶部提示入口直达。
8. **日常提醒**：切到“提醒”，点右上角＋；今天、明天、后天可直接选，事项正文可点编辑，圆形勾选完成。新建、修改和删除需家长核验；“知道了”、10 分钟后再提醒、完成/恢复完成直接可用，都不加分。顶部待处理入口支持连续处理，计数即时减少，全部处理后自行关闭；底部“指令”仍能整理提醒和查询积分。
9. **验证方式**：右上角设置 → 家长验证，首次可以直接设置6位PIN并确认，或选择算术题。已设置后修改需通过当前方式；修改PIN要输入并确认新PIN，再验证当前PIN。算术题是轻量防误触，孩子也可能答出。

## 伙伴怎么长大

累计获得 1 积分对应 1 成长值；可用积分用于礼品兑换和道具购买。五个形态的累计门槛为 0、30、100、250、500，500 之后每多 250 成长值获得一颗成长星，750 时获得第一颗。初始示例累计 128 分，因此伙伴处于第三阶段，距离第四阶段还有 122 分。

晶叶幼龙从晶卵初醒成长为星辉守护龙，水豚从初见团团成长为星光守护者。每次真实加分有即时回应，跨门槛有升级提示；“成长足迹”展示五阶段形象与印记。消费不退级，照料不刷成长 XP，更换物种不重置。

探索进度单独记录照料旅程，不能当积分花：累计 4/10/18/28/40/56 依次解锁微光森林、晶石洞穴、云海浮岛、流星营地、星环港湾、极光山巅。每日免费次数和当天清单按服务器家庭日期更新；库存、里程和收藏永久保留。没有连签、饥饿、生病或忘记照顾的惩罚。免费摸摸始终可用，系统开启“减少动态效果”时保留静态姿态、特效与文字反馈。

## 照片怎么保存

支持 JPEG、PNG、WebP，客户端选择文件不超过 8 MiB、1600 万像素。浏览器在本机解码、居中裁剪成方形并缩为 192×192 小头像，重新编码去除原图元数据，预览后再保存。原图不发往服务器或模型；重新编码的头像随家庭状态在自建服务器保存，并同步到同一家庭设备，离线版只保存在本机。

保存前有家长核验，支持移除头像。最终图片 data URL 上限 160000 字符，接口默认体积上限 256 KiB；拒绝 SVG、远程图片 URL、MIME/标识不符、无效编码及超限数据。服务端做格式及基本标识校验，实际图像解码由浏览器完成。v0.6 的照片验证使用合成图片，没有使用真实儿童照片。

## 共享服务器

运行需要 Node.js 22 或更新版本，无运行时第三方依赖；不需要先执行 npm install。

```sh
node server.cjs
```

默认地址为 `http://127.0.0.1:4178`。新家庭默认未设置验证方式；家长直接在页面的设置入口完成首次配置，不需要控制台密码。设置前公开日常操作可用，受限业务须先完成家长设置。共享配置保存在服务器，刷新、重启或换设备不会重新初始化；旧版已有验证凭据继续有效。密码不会出现在公开API、业务导出或日志中，也不存成明文。

尚未配置的家庭由第一次成功保存者设置验证方式；交给家庭使用前由家长完成。已经配置的密码不能从公开页面免验证重置。本次旧演示的初始化恢复仅对已确认的演示数据做一次带备份的本机迁移，不是对所有旧账户自动重置。

可选环境变量：

- `DATA_FILE`：数据文件路径，默认 `data/state.json`。数据包含私有家长验证散列，不能公开发布。
- `PARENT_PIN`：可选的首次部署预配置PIN；建议6位。不设置时由家长在页面初始化；已有数据的验证状态不会被此环境变量覆盖。
- `HOST` / `PORT`：默认 `127.0.0.1` / `4178`。
- `PUBLIC_ORIGIN`：在可信反向代理后运行时指定实际公开来源，如 `https://family.example.com`；示例域名需替换。
- `TZ`：家庭时区；本 Demo 使用 `Asia/Shanghai` 解释日期。

同一 Wi-Fi 下体验可按实际需要用以下方式启动，然后手机和 iPad 打开电脑的局域网 IP、端口 4178：

```powershell
$env:HOST='0.0.0.0'
$env:TZ='Asia/Shanghai'
node server.cjs
```

普通局域网 HTTP 可以测试积分与提醒，但网页麦克风通常需要 HTTPS；实际部署需配置 HTTPS。页面每 5 秒同步，发生版本冲突会保留输入并要求重新确认。服务器断开时不会把失败的共享操作伪装成本地保存。本轮没有部署到用户的外部服务器。

## AI 和语音

没有配置模型时，表单与“指令”明确显示 **指令演示**，由本地规则整理，不联网。加分与常用项管理使用不同情境：前者只填一次加分，后者只改模板，不会串成记账。通用入口仍支持常见中文日期/时间、礼品、提醒改期和真实余额查询。复杂表述或不明确目标会请求补充，可直接手动修改表单。

服务器已提供 OpenAI 兼容的 Chat Completions 适配：在服务器进程环境中设置 `AI_API_KEY`、`AI_BASE_URL`（通常以 `/v1` 结尾）和 `AI_MODEL` 后启动。默认模型名为 `gpt-4.1-mini`，可按自己的服务商修改。凭证只由服务器读取，不填写到客户端源码。模型需支持 JSON 输出；远端地址使用 HTTPS，本机模型可以使用 localhost HTTP。

连接真实服务后，点击 AI 整理按钮会按所配置服务商的规则产生调用费用，并发送本次文字和当前操作所需的最小上下文。常用项管理只发送模板信息；加分发送积分汇总和可用模板；通用入口另含必要礼品和待办。**不会发送孩子照片、完整历史账本、家长密码或核验答案**，服务器在将状态交给助手前就移除头像。模型只能提出候选；场景、金额、日期、余额、兑换条件及权限仍由程序校验。只读数字查询由账本计算。失败时保留输入，迟到回答不能覆盖后来手动修改的表单。

本轮没有配置真实模型凭证，外部调用的成功尚未验证；自动测试中的提供方是模拟响应，用于验证超时、错误、上下文隔离和输出校验。

按键语音使用浏览器 SpeechRecognition，可能依赖网络、Safari/Siri 设置和麦克风权限；也可使用系统键盘听写或直接打字。本轮没有实机录音或语音识别验证。**免触摸唤醒没有启用**，不承诺网页在后台、锁屏或退出后监听。

## iPad 使用与提醒边界

- 使用 Safari 打开服务器地址后，可通过“分享 → 添加到主屏幕”创建应用图标。这是 Web App，没有 IPA/APK 安装包。
- 为 iPad mini 4 / iPadOS 15.8.7 保留 ES5 脚本、WebKit 布局回退、原生日期时间输入和至少 48px 的主要触控目标；视口模拟不能替代 Safari 真机验证。
- 页面默认铺满可用视口，系统浏览器工具栏由系统控制。设置中的“屏幕常亮”仅在浏览器实际取得 Screen Wake Lock 且尚未释放时显示常亮；不支持或拒绝时显示对应短状态。目标旧 iPad 可在“设置 → 显示与亮度 → 自动锁定”中按需调整，页面不能保证阻止系统锁屏。
- 到点提示由前台页面运行。页面重开后会识别漏过的定时提醒；“知道了”保留未完成事项；“10 分钟后”推迟本次提示，完成不加分。跨日未完成事项仍可找到，今日“提前准备”区会显示进入提前天数范围的重要事件。没有定时的事项只显示，不会凭空响铃。
- 后台/锁屏推送、系统级唤醒、连续 8 小时稳定性、真实麦克风和音量/距离测试均未验证。重要事件与近期待办分开；重要事件提前天数用于提前展示，不等于可靠后台通知。

## 数据规则和权限

一户一个孩子一套账本，`可用 = 累计获得 - 礼品支出 - 道具支出`。累计不清零、不因消费减少。加分必须是正整数并有具体原因，补记仅限今天已过去的时间。礼品必须启用、余额足够并满足分类日期；正好够分也能兑换或购买道具，没有月度次数或额度上限。月底暂按每月最后 3 个自然日，可在设置调整。

申请不扣分；同一礼品不会重复积压申请，换礼品会替换待确认的旧申请。家长确认时重验当前价格、余额和日期。历史名称、原因和分值保持当时快照，修改模板不改变旧账。错误加分的冲正/撤销与礼品履约状态仍未定案，本版不擅自修改累计口径。

敏感操作必须取得与本次完整内容和数据版本绑定的短期单次授权；PIN 采用服务端加盐 scrypt，验证码限次限时，错误尝试有速率限制。页面隐藏和本地状态均不构成服务端授权。公开的日常操作不会改变积分账本。

服务器采用原子文件替换、版本冲突和动作 ID 幂等保护，响应丢失后的同一笔重试不会重复记账。部署假设一个 Node 进程写一个数据文件，不支持多个进程同时写同一个文件。源码包排除运行数据、凭证和依赖目录。家庭记录导出只包含业务状态，不包含家长 PIN 散列。备份前停止服务器，妥善保存整个数据文件。
