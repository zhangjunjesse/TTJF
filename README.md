# 小小向前 · SQLite 多家庭版 v0.15.0

> 每一步，都算数。

邮箱账号可以创建或加入多个家庭，每个家庭保留一个孩子、一套积分账本和一个伙伴农场。新家庭从零开始；验证邮箱后才能访问家庭数据。所有者可以管理邀请和成员、改家庭名称、交接所有权及删除家庭；家长可主动退出，账号可在处理完拥有的家庭后注销。积分、礼品、提醒和家长逐笔核验沿用原规则，v0.12农场画面保持不变。

家长在自定义加分或核对常用行为时，可以拍照或从相册选最多 3 张照片。照片只随本次加分保存。打开「积分记录」即可翻看、放大照片，同一家庭内查看照片无需再次验证。

账号、会话、家庭成员、账本、农场和操作回执保存在本机 SQLite。一个 Node.js 服务进程通过事务处理并发与重试；默认启动无需 PostgreSQL 或 Docker。退出或切换家庭会清理旧页面和请求。SaaS 不把业务数据、草稿或 PIN 存在浏览器缓存，也不会在数据库故障时改成本地记账。页面隐藏后只保留普通内存草稿，服务器确认仍是同一会话、账号和家庭后再恢复；设备音效仅保存一个独立布尔偏好。家庭日期统一上海，作物仍按实际时长成熟。当前数据库和单机部署由[v0.15 SQLite 决定](docs/sqlite-migration.md)拥有；基础账号/租户边界由[多家庭 SaaS 决定](docs/saas-design.md)拥有，新增生命周期、恢复与完整验收由[v0.14决定](docs/saas-completion.md)拥有，业务与视觉规则仍由[农场决定](docs/farm-design-proposal.md)等原记录拥有。

本轮迁移与实际验证见[v0.15 SQLite 验证记录](docs/sqlite-verification.md)。v0.14 的227/42/21/27项验收是历史结果，不代替本轮 SQLite 回归；跨页签退出、家庭隔离、一次性授权和账本原子性继续作为验收要求。

## 本机启动

需要 Node.js 22.17或更新版本。使用 Node 内置 SQLite，无需另外安装数据库；在项目目录执行：

```powershell
npm ci --ignore-scripts
npm run db:init
# 在私有 .env.saas.local 中填写初始账号密码和 SMTP 授权码
npm start
```

打开 <http://127.0.0.1:4180/>。启动时自动创建私有 `data/ttjf.sqlite`，并按 `INITIAL_ACCOUNT_EMAIL` / `INITIAL_ACCOUNT_PASSWORD` 补建缺失的初始账号；初始邮箱默认 `391504704@qq.com`，密码仅从私有配置读取。运维指定的初始账号可直接登录，已有账号的密码、验证状态和家庭数据不会被重启覆盖；不预建家庭。其他账号仍正常注册、通过真实邮件验证后创建或加入家庭。旧环境的账号和数据不会自动迁移。

本机使用 HTTP 回环地址，账号和业务规则与部署版本相同；验证、邀请和恢复邮件通过配置的 SMTP 真实发送。普通启动不再默认写开发文件邮件，缺少邮件配置会报错；只有测试显式指定 `DEV_MAIL_DIR` 才使用受限的本地捕获。`npm run db:init` 生成 QQ SMTP 配置模板但不包含密码或授权码。若本机已有私有 `data/initialize-private.ps1`，运行 `pwsh -File tools/start-saas.ps1` 可在配置缺失时恢复它并启动服务；修改配置后可加 `-Restart` 重启已登记的项目进程。脚本要求 PowerShell 7。私有初始化脚本、运行配置及数据库均不进入 Git。详见[初始账号决定](docs/saas-initial-user.md)。

对外内测需要配置真实域名、HTTPS、私有持久化目录与SMTP，再以生产环境运行 Node 服务。[运行与数据操作](docs/saas-operations.md)给出配置、数据库备份、旧家庭导入和恢复步骤。本轮只启动本机版本，未发布外部服务，也未接入支付。

1. **开启小院**：首页点“开启我的小院”，领取一块成熟萝卜田。收获3份萝卜后，打开“背包·建设”，预览小花盆，确认兑换，再摆在门口。欢迎礼田只发一次；共享模式刷新、换设备或换伙伴不能重领。
2. **播种与收获**：首页“播种”可一次种满空田；展开小院后，点某块田可单独选择品种。种子免费，三种作物都是8小时成熟、每块田收获3份。播种自动浇水；额外浇水只是互动。离开页面继续生长，成熟后等待收获，不枯萎、不自动重种。
3. **每天来陪朋友**：伙伴投喂、清洁、训练免费，只产生互动反馈。动物每天第一次照料留下记录，累计3次得到图鉴卡、7次学会小动作；漏一天不清零。小鸡最先入住，100成长值时小兔来到小院。
4. **自主建设**：作物放在背包里，用来兑换装饰和升级小屋，不换成家庭积分。效果预览不扣材料；确认后原子结算。装饰获得一次后可免费摆放、收起和换位；小屋升级立即生效，不再等建造时间。
5. **保留成长与回忆**：点伙伴名字看成长足迹；展开小院 → 收藏 → 伙伴设置，可切换晶叶龙/太空水豚并改名。田地、背包、成长与动物记录共用。旧探索和旧道具仍可查看，旧道具可手动用于特别互动。开启小院后不再出售补给，互动不再增加旧探索，也不自动退款或删除旧库存。
6. **记录现实进步**：首页“加分”选择常用行为，或点＋新增本次行为；行为名称与正整数分值必填，原因选填，名称与原因可独立表达；提交需要本次家长核验。自定义可勾选“同时存为常用”，一次确认同时保存记录与模板。改本次分值不会改历史模板。表单里的星光入口按需展开指令填写，默认使用本地“指令演示”。
7. **礼品与提醒**：礼品先申请、家长确认后扣分；提醒的完成、知道了、稍后提醒不加分，新建/修改/删除需家长核验。资料、头像、积分记录与常用项管理入口保持可达。

首页自动适配横竖屏，无需上下寻找余额、加分、日常农场按钮和常用行为。展开小院可以单指/鼠标拖动、用按钮或滚轮缩放、一键回中，点场景或田地栏打开对应操作；正常状态同步不重置镜头。长列表与详情在浮动面板内滚动，选中对象会避让面板。日夜按钮只改变景色，不改变成熟或照料规则。3D暂不可用时仍可用按钮完成日常动作，界面会说明画面状态。

## 伙伴怎么长大

累计获得1积分对应1成长值；五阶段门槛为0、30、100、250、500。500之后每多250成长值获得一颗成长星，750时第一颗。相应可种田数为2、3、4、5、6。SaaS新家庭为0成长值，开启小院后有2块田；旧离线示例的128成长值和4块田不作为新家庭初始化数据。

消费礼品、种植收获、照料、兑换装饰、更换伙伴都不改变成长。农场库存单独记为萝卜、草莓和向日葵数量，没有金币、体力、饥饿、连续签到或加工链。详细开放条件、初始价格与边界见[农场规则](docs/farm-design-proposal.md)。价格属于首版平衡值，未经过长期每日试玩验证。

## 照片怎么保存

点击首页左上角的“上传头像”进入孩子资料，选择图片预览后保存；已设置头像时入口显示“更换头像”，也可在资料页移除。

支持 JPEG、PNG、WebP，客户端选择文件不超过 8 MiB、1600 万像素。浏览器在本机解码、居中裁剪成方形并缩为 192×192 小头像，重新编码去除原图元数据，预览后再保存。原图不发往服务器或模型；重新编码的头像随家庭状态在自建服务器保存，并同步到同一家庭设备，离线版只保存在本机。

保存前有家长核验，支持移除头像。最终图片 data URL 上限 160000 字符，接口默认体积上限 256 KiB；拒绝 SVG、远程图片 URL、MIME/标识不符、无效编码及超限数据。服务端做格式及基本标识校验，实际图像解码由浏览器完成。v0.6 的照片验证使用合成图片，没有使用真实儿童照片。

## 旧单户共享服务（兼容入口）

以下段落只描述保留的单家庭文件服务。SaaS启动与账号权限使用上面的新入口；此处匿名首次设置和局域网HTTP不适用于SaaS。

旧文件服务运行需要 Node.js 22或更新版本，无运行时第三方依赖；可直接执行：

```sh
node server.cjs
```

默认地址为 `http://127.0.0.1:4178`。新家庭默认未设置验证方式；家长直接在页面的设置入口完成首次配置，不需要控制台密码。设置前公开日常操作可用，受限业务须先完成家长设置。共享配置保存在服务器，刷新、重启或换设备不会重新初始化；旧版已有验证凭据继续有效。密码不会出现在公开API、业务导出或日志中，也不存成明文。

尚未配置的家庭由第一次成功保存者设置验证方式；交给家庭使用前由家长完成。已经配置的密码不能从公开页面免验证重置。本次旧演示的初始化恢复仅对已确认的演示数据做一次带备份的本机迁移，不是对所有旧账户自动重置。

可选环境变量：

- `DATA_FILE`：数据文件路径，默认 `data/state.json`。数据包含私有家长验证散列，不能公开发布。
- `PARENT_PIN`：可选的首次部署预配置PIN；建议6位。不设置时由家长在页面初始化；已有数据的验证状态不会被此环境变量覆盖。
- `HOST` / `PORT`：默认 `127.0.0.1` / `4178`。
- `PUBLIC_ORIGIN`：在可信反向代理后运行时指定实际公开来源，如 `https://family.example.com`；示例域名需替换。
- `TZ`：家庭时区；本 Demo 使用 `Asia/Shanghai` 解释日期。

同一 Wi-Fi 下体验可按实际需要用以下方式启动，然后手机和 iPad 打开电脑的局域网 IP、端口 4178：

```powershell
$env:HOST='0.0.0.0'
$env:TZ='Asia/Shanghai'
node server.cjs
```

普通局域网 HTTP 可以测试积分与提醒，但网页麦克风通常需要 HTTPS；实际部署需配置 HTTPS。页面每 5 秒同步，发生版本冲突会保留输入并要求重新确认。服务器断开时不会把失败的共享操作伪装成本地保存。本轮没有部署到用户的外部服务器。

## AI 和语音

没有配置模型时，表单与“指令”明确显示 **指令演示**，由本地规则整理，不联网。加分与常用项管理使用不同情境：前者只填一次加分，后者只改模板，不会串成记账。通用入口仍支持常见中文日期/时间、礼品、提醒改期和真实余额查询。复杂表述或不明确目标会请求补充，可直接手动修改表单。

服务器使用兼容 OpenAI Chat Completions 的接口。在服务器进程环境中设置 `AI_API_KEY`、`AI_BASE_URL`（通常以 `/v1` 结尾）和 `AI_MODEL` 后启动。默认模型名为 `gpt-4.1-mini`，可按自己的服务商修改。凭证只由服务器读取。通用聊天的工具调用需要模型支持原生 `tool_calls`，模型在回复正文中给出的 JSON 示例按文字展示。独立的表单整理入口使用 JSON 输出。远端地址使用 HTTPS，本机模型可以使用 localhost HTTP。

连接真实服务后，点击 AI 整理按钮会按所配置服务商的规则产生调用费用，并发送本次文字和当前操作所需的最小上下文。常用项管理只发送模板信息；加分发送积分汇总和可用模板；通用入口另含必要礼品和待办。**不会发送孩子照片、完整历史账本、家长密码或核验答案**，服务器在将状态交给助手前就移除头像。模型只能提出候选；场景、金额、日期、余额、兑换条件及权限仍由程序校验。只读数字查询由账本计算。失败时保留输入，迟到回答不能覆盖后来手动修改的表单。

设置 `AI_FORM_ONLY=1` 可仅在「新建常用行为」中启用外部模型。这个入口发送固定任务和家长输入的那句话，其余指令继续用本地规则。修改服务端配置后重启生效。

登录并选择家庭后，点底部「首页」与「提醒」之间的圆球打开家长助手。填写表单时，标题栏也有同款圆球。会话按账号和家庭存入服务端 SQLite，清空会话会取消未提交的助手草稿，已保存的积分和家庭规则保留。助手的加分和兑换建议先回到业务表单核对，沿用原有家长授权和记账回执。

通用聊天默认使用本地模式。设置 `AI_CHAT_ENABLED=1` 并配置模型后，每轮对话都交给模型理解。模型读取本轮时间、必要对话片段和工具说明，自行决定直接回答、追问或调用工具。修改 `config/assistant/system.md` 可调整交流和办理原则，修改 `config/assistant/tools.json` 可调整工具说明，重启服务后生效。家庭身份、工具参数、家长验证和实际记账由服务端校验。

聊天气泡上的「本地」和「AI」表示那条回复的实际来源。语音转写使用独立配置；启用通用模型聊天后，新对话轮次会发送本轮输入及必要上下文，历史消息保留原来源。

用 `npm run eval:assistant -- --list` 查看意图用例。配置测试用模型后，运行 `npm run eval:assistant -- --group award` 回放加分场景，也可用 `--case` 选单案、`--repeat 3` 重复验证。评测使用合成家庭和固定北京时间，显式调用所选模型，会产生模型请求费用。每次运行将实际回复、核对结果和耗时写入独立目录；`--out` 可指定目录。日常 `npm test` 运行本地回归和测评工具自身的检查。

可以先问「现在几点」「35+100 等于多少」，再问「我家有多少可兑换积分」或「今天整理书包加 4 分」。前两句可直接作答，后两句分别需要真实家庭账本和待确认草稿。回复旁的「AI」表示本轮使用了模型。联网聊天请求失败时，原消息保留，可点击重试。本地模式的回复标为「本地」。

输入「以后自己读书满二十分钟，奖励五分」，点「帮我填好」，表单会把阅读时长保留在名称里，并填入 5 分。只说了行为时，可以在表单里补积分。家长核对后点「保存」才会建立常用行为。

轻点首页底栏中央的声波按钮可以打开家长助手。想直接说话，就按住这个按钮，等出现「正在听你说」再开口，整个过程都不用换手指。进入对话后，轻点输入框可以打字，按住输入框可以说话。

录音时会显示蓝色渐变和波形，支持网页振动的手机在收音开始时还会轻震一下。正常松手即可发送。上滑到「松开取消」可以放弃这次录音。周围有人说话时，可以右滑到「松开转文字」，松手核对名字和分数后再发。已有文字草稿或麦克风启动较慢时，识别结果也会留在输入框里。

点输入框旁的麦克风也可以听写成草稿。火山听写到 60 秒会自动收尾，把定稿放进输入框。

服务端配好火山凭证后，助手默认通过本站把录音传给火山识别。松手收到整段定稿后才会发送给助手，取消会停止传输并丢弃这条消息。未配置凭证时使用浏览器普通话听写，读音或分数有分歧时会留下文字供核对。手机访问需要 HTTPS 并允许使用麦克风。配置、计费和代理设置见[运行与数据操作](docs/saas-operations.md#家长助手语音识别)。

## iPad 使用与提醒边界

- 在 iPhone 或 iPad 的 Safari 中打开网页，点“分享 → 添加到主屏幕”。如果看见“作为网页 App 打开”，请打开它。从新图标进入后，Safari 的地址栏和底部工具栏会收起。iPhone 顶端仍会显示系统时间、信号和电量。[Apple 主屏幕网页 App 指南](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)
- 业务界面保留ES5，3D场景使用Three.js 0.160.1并构建为Safari 15可读的普通IIFE脚本，不依赖import maps、ES模块入口或运行时CDN。DPR上限1.25、目标30fps；主点击区至少48px。视口模拟和WebGL 1检查不能替代Safari真机验证。
- 页面默认铺满可用视口，系统浏览器工具栏由系统控制。设置中的“屏幕常亮”仅在浏览器实际取得 Screen Wake Lock 且尚未释放时显示常亮；不支持或拒绝时显示对应短状态。目标旧 iPad 可在“设置 → 显示与亮度 → 自动锁定”中按需调整，页面不能保证阻止系统锁屏。
- 到点提示由前台页面运行。页面重开后会识别漏过的定时提醒；“知道了”保留未完成事项；“10 分钟后”推迟本次提示，完成不加分。跨日未完成事项仍可找到，今日“提前准备”区会显示进入提前天数范围的重要事件。没有定时的事项只显示，不会凭空响铃。
- 后台/锁屏推送、系统级唤醒、连续 8 小时稳定性、真实麦克风和音量/距离测试均未验证。重要事件与近期待办分开；重要事件提前天数用于提前展示，不等于可靠后台通知。

## 数据规则和权限

一户一个孩子一套账本，`可用 = 累计获得 - 礼品支出 - 历史道具支出`。累计不清零、不因消费减少。加分必须填写行为名称和正整数分值，原因选填；名称与原因可独立表达，无需重复填写同一内容。补记仅限今天已过去的时间。礼品必须启用、余额足够并满足分类日期；正好够分也能兑换，没有月度次数或额度上限。开启小院后停止新道具购买，历史支出仍计入账本。月底暂按每月最后 3 个自然日，可在设置调整。

申请不扣分；同一礼品不会重复积压申请，换礼品会替换待确认的旧申请。家长确认时重验当前价格、余额和日期。历史名称、原因和分值保持当时快照，修改模板不改变旧账。错误加分的冲正/撤销与礼品履约状态仍未定案，本版不擅自修改累计口径。

敏感操作必须取得与本次完整内容和数据版本绑定的短期单次授权；PIN 采用服务端加盐 scrypt，验证码限次限时，错误尝试有速率限制。页面隐藏和本地状态均不构成服务端授权。公开的日常操作不会改变积分账本。

SaaS用一笔SQLite事务提交家庭状态、版本、核验配置和动作回执，并消费本次授权。操作ID、版本、家庭、用户及会话共同构成校验边界；部署采用单机单进程，数据库文件不放在网络共享盘。旧单户服务仍为一个Node进程写一个私有JSON文件，两种存储路径不自动合并。普通页面导出只有业务状态；运维私有备份另含家长核验摘要和动作回执，必须保存在私有位置。备份与导入见[数据操作](docs/saas-operations.md)。

```powershell
npm test

npm run test:browser

```
